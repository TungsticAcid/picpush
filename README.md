# 立体拼合辅助程序

考公立体拼合题型辅助训练工具。在 3D 场景中拼合半透明彩色组件，培养空间想象能力。

## 功能

- **3D 场景** — 自由旋转/缩放/平移视角，无死角观察
- **组件操作** — 拖动、六方向移动、三轴 90° 旋转
- **碰撞检测** — 组件重叠时红色闪烁提示，阻止非法放置
- **网格吸附** — 方块对齐网格单元中心，精确拼合
- **轴对齐** — 旋转后自动吸附最近的正交朝向
- **形状编辑器** — 分层 2D 网格自定义组件形状，支持保存为预设
- **预设管理** — 内置 7 种形状，用户预设持久化存储
- **属性编辑** — 颜色取色器 / RGB 滑块 / 透明度调节
- **全局操作** — 一键清空、整体移动/旋转所有组件
- **PWA** — 可安装到手机主屏幕，离线使用

## 技术栈

React + TypeScript · Three.js (react-three-fiber) · Zustand · Vite · vite-plugin-pwa

## 开发

```bash
npm install
npm run dev      # 启动开发服务器
npm run build    # 构建生产版本到 dist/
```

## 使用

1. 顶部 `+添加` 下拉菜单选择合适的预设形状添加组件
2. 点击组件进入编辑模式，底部面板移动/旋转/调整属性
3. 拖动组件在平面上移动；`⋯` 菜单可整体操作
4. `✎` 打开形状编辑器，自定义或管理预设
